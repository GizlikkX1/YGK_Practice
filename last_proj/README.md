# TaskBoard

Командная система управления задачами с канбан-доской: доски с упорядоченными колонками, задачи с исполнителем, сроком и приоритетом, перетаскивание между этапами, история изменений и обновления в реальном времени.

Интерфейс повторяет макет TaskBoard из Figma: та же палитра, шрифт Inter, размеры, радиусы, тени и все экраны основного и альтернативных сценариев.

## Стек

Все зависимости бесплатные, с открытыми лицензиями.

| Часть | Технологии |
|---|---|
| Backend | Python 3.10+, FastAPI, SQLAlchemy 2, SQLite, Uvicorn, WebSocket |
| Frontend | HTML, CSS, JavaScript (ES-модули, без сборки и без фреймворков) |
| Шрифт | Inter (SIL Open Font License, лежит в `frontend/fonts`) |
| Тесты | pytest, httpx |

Backend отдаёт и REST API, и сам фронтенд, поэтому приложение запускается одной командой.

## Запуск

Нужен **Python 3.10 или новее** и любой современный браузер (Chrome, Firefox, Edge, Safari).

### Linux / macOS

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Shell fish (например, Arch Linux)

```fish
cd backend
python3 -m venv .venv
source .venv/bin/activate.fish
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Можно обойтись без активации окружения: `.venv/bin/pip install -r requirements.txt`, затем `.venv/bin/uvicorn app.main:app --reload`.

### Windows (PowerShell)

```powershell
cd backend
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте **http://127.0.0.1:8000**.

При первом запуске создаётся база `backend/taskboard.db` с демо-данными из макета: команда из шести человек (Соколов, Тюрин, Шлыков, Гукасян, Гречишкин, Кириллов), три доски и задачи, в том числе одна просроченная. Сроки считаются от текущей даты, поэтому доска всегда выглядит «живой».

- Документация API (Swagger): http://127.0.0.1:8000/docs
- Начать с чистой базы: остановите сервер и удалите `backend/taskboard.db`.
- Запустить без демо-данных: `TASKBOARD_SEED=0 uvicorn app.main:app` (в PowerShell: `$env:TASKBOARD_SEED=0`).
- Открыть с другого устройства в локальной сети: `uvicorn app.main:app --host 0.0.0.0 --port 8000`.

## Пользователи и роли

Это демо без паролей: текущий пользователь передаётся в заголовке `X-User-Id`. Сменить пользователя можно двумя способами:

- нажать на аватар в левом нижнем углу;
- открыть раздел **Настройки**.

Роли на доске:

- **Владелец** управляет структурой доски (колонки, порядок, финальная колонка, архив) и участниками.
- **Участник** работает с задачами: создаёт, редактирует, назначает, перемещает и удаляет их.

Исполнителем может быть только участник доски. Если нужного человека нет, владелец приглашает его по email прямо из выбора исполнителя.

**Реальное время.** Откройте приложение во второй вкладке, выберите там другого пользователя и, например, переместите задачу. В первой вкладке доска обновится сама и появится уведомление «Доска обновлена».

## Что реализовано (по сценариям макета)

| Экран макета | Где в приложении |
|---|---|
| 1 Мои доски | Главная: карточки досок с прогрессом по колонкам, избранное, архив, таблица «Назначено мне» |
| 2 Доска | Упорядоченные колонки, карточки (приоритет, срок, комментарии, исполнитель), подсветка просрочки, поиск и фильтры |
| 3 Новая задача | Кнопка «+ Задача», «+» в заголовке колонки или «Добавить задачу». Задача добавляется в конец колонки |
| 4 Перетаскивание | Drag-and-drop с индикатором «Задача встанет сюда (позиция N)» и исходным местом. Меняются колонка и позиция, копия не создаётся |
| 5 Карточка задачи | Клик по карточке: редактирование полей, комментарии, вкладка «История изменений» (автор, действие, было → стало, время) |
| 6 Задача завершена | Перемещение в финальную колонку → уведомление с кнопкой «Отменить» |
| А1 Ошибки валидации | Пустое название или срок в прошлом: поля подсвечены, кнопка «Создать задачу» неактивна (проверка и на сервере) |
| А2 Создание доски | Шаблоны колонок, редактор колонок (перетаскивание строк, переименование, финальная колонка), участники |
| А3 Удаление колонки | Меню «⋯» колонки → диалог: перенести задачи в другую колонку (по умолчанию) или удалить их |
| А4 Без перетаскивания | Меню «⋯» карточки («Переместить в», «Поднять выше / Опустить ниже», «В начало колонки») и клавиатура: Пробел — взять задачу, стрелки — переместить, Пробел — положить, Esc — отмена, Alt+↑/↓ — сдвинуть |
| А5 Исполнитель не найден | Поиск в списке исполнителей → «Пригласить и назначить» по email или «Оставить без исполнителя» |
| А6 Ошибка сохранения | Баннер «Нет соединения с сервером» с повтором через 5 с. Неудачное перемещение откатывается, карточка помечается «Не сохранено», в уведомлении есть «Повторить». Изменения других участников приходят по WebSocket |

Дополнительно:

- переименование доски и колонок;
- цвет колонок;
- окно «Колонки» для настройки существующей доски;
- разделы «Мои задачи», «Участники», «Настройки».

## Модель данных

```
User ─┬─< BoardMember >─ Board ─< BoardColumn ─< Task ─< TaskHistory
      │   (role, favorite)        (position,     (position,  (action, было → стало)
      │                            is_final)      column_id) └< Comment
      └─ assignee / author ───────────────────────┘
```

- Задача ссылается ровно на одну колонку (`column_id`) и хранит место в ней (`position`). Перемещение меняет только эти два поля, поэтому изменение структуры доски никогда не дублирует задачи.
- Одна колонка доски отмечена как финальная: задачи в ней считаются завершёнными (`is_done`, `completed_at`).
- В историю пишутся основные изменения: создание, перемещение между колонками, смена исполнителя, срока, приоритета и названия. Кроме того, при удалении колонки фиксируется перенос её задач.
- Колонку с задачами нельзя удалить без явного решения: `DELETE /api/columns/{id}?strategy=move&target_column_id=…` или `strategy=delete`.

## Тесты

```bash
cd backend
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают:

- CRUD досок, колонок и задач;
- валидацию;
- перемещения и порядок задач;
- сохранение состояния доски;
- историю изменений;
- роли и приглашения;
- удаление колонки с задачами;
- события WebSocket.

## Структура репозитория

```
backend/
  app/
    main.py          FastAPI: API /api, WebSocket /ws, раздача фронтенда
    models.py        модель данных (SQLAlchemy)
    schemas.py       схемы запросов и ответов, валидация
    services.py      права доступа, порядок задач, история, сериализация

    seed.py          демо-данные из макета
    routers/         users, boards, columns, tasks, ws
  tests/             pytest
  requirements.txt
frontend/
  index.html
  css/               tokens.css (палитра и тени из макета), компоненты, страницы, доска, карточка задачи
  js/
    main.js          роутер и запуск
    api.js           клиент REST API
    realtime.js      WebSocket, статус соединения, переподключение
    ui/              меню, модальные окна, уведомления, выбор исполнителя, общие компоненты

```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TASKBOARD_DATABASE_URL` | `sqlite:///backend/taskboard.db` | строка подключения SQLAlchemy |
| `TASKBOARD_SEED` | `1` | `0` — не создавать демо-данные |
| `TASKBOARD_WORKSPACE` | `Команда Mobile` | название команды в боковом меню |
