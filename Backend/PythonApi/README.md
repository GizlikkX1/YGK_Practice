# Практика: API для барбершопа "Бритва"

Страница записи на React и бэкенд на Python. Бэкенд сделал на FastAPI, он лежит в папке `app/`.

## Что сделано по заданию

**Задание 1.** `GET /categories` отдает список всех категорий и сколько в каждой услуг:

```json
[
  { "id": 1, "name": "Стрижки и укладки", "servicesCount": 5 },
  { "id": 2, "name": "Маникюр и педикюр", "servicesCount": 5 },
  { "id": 3, "name": "Брови и ресницы", "servicesCount": 4 },
  { "id": 4, "name": "Спа-процедуры", "servicesCount": 4 }
]
```

**Задание 2.** `GET /categories/{category_id}` отдает одну категорию:

```json
{ "id": 1, "name": "Стрижки и укладки", "servicesCount": 5 }
```

Если категории с таким id нет, сервер отвечает кодом 404 и текстом `Category not found`.

Еще с прошлых заданий остались эндпоинты для страницы записи, их я тоже перенес на Python:

- `GET /api/booking/today` - сегодняшняя дата
- `GET /api/slots?day=18&month=10&year=2026` - свободное время на день (месяцы считаются с нуля, ноябрь это 10)

Категории можно открыть и через `/api/categories`, так удобнее фронтенду.

## Как запустить

Нужны Python 3.10 или новее и Node.js 18 или новее.

Сначала бэкенд. Ставлю зависимости в виртуальное окружение, потому что на Arch pip без него ругается на `externally-managed-environment`:

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
```

Можно и активировать окружение: `source .venv/bin/activate` (в fish `source .venv/bin/activate.fish`). Тогда хватит просто `uvicorn ...`.

Когда сервер запущен, `http://localhost:8000/docs` открывает страницу, где можно потыкать все эндпоинты.

Потом фронтенд, во втором терминале:

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:3000`. Vite сам пересылает запросы `/api` и `/categories` на бэкенд, на порт 8000.

## Тесты

```bash
.venv/bin/pytest
```

Тесты проверяют оба задания (в том числе 404 для несуществующей категории) и старые эндпоинты со слотами.

## Как проверить ошибки и загрузку

У запросов к `/api` есть задержка 650 мс, чтобы было видно "Загрузка...". Ее можно поменять через переменную `API_DELAY_MS`.

- `http://localhost:3000/?simulateSlotsError=1` - ошибка при загрузке слотов
- `http://localhost:3000/?simulateTodayError=1` - ошибка при загрузке даты

В обоих случаях появляется сообщение и кнопка, чтобы попробовать еще раз.

## Что где лежит

- `app/main.py` - сами эндпоинты
- `app/database.py` - данные: категории и расписание
- `app/schemas.py` - модели ответов
- `tests/` - тесты на pytest
- `src/` - фронтенд на React
