# frontend-3-practice

React-версия страницы выбора даты и времени для барбершопа «Бритва». Внешний вид основан на предыдущей HTML/CSS-верстке, а интерактивность реализована компонентами React и хуком `useState`.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер Vite:

```bash
npm run dev
```

Откройте локальный адрес, который появится в терминале.

Для проверки production-сборки:

```bash
npm run build
```

## Реализовано

- По умолчанию выбрана сегодняшняя дата, сразу отображаются её временные слоты.
- Выбор дня обновляет доступные слоты и сбрасывает ранее выбранное время.
- Выбор доступного слота обновляет блок «Ваша запись».
- Стрелки переключают месяцы; перейти к месяцу раньше текущего нельзя.
- Прошедшие дни приглушены и недоступны для выбора.
- В блоке записи отображаются день недели, дата, месяц, год и выбранное время.

Расписание слотов демонстрационное: доступность формируется детерминированно на основе выбранной даты и времени.
