# frontend-2-practice — выбор даты и времени

Небольшая страница записи в барбершоп «Бритва». Вёрстка, стили и логика разделены на отдельные файлы; используется только нативный JavaScript, без фреймворков.

## Файлы проекта

- `index.html` — разметка страницы.
- `styles.css` — оформление и адаптивные стили.
- `script.js` — данные, состояние, функции календаря, рендер и обработчики событий.
- `images/` — папка для изображений (в текущем макете изображения не используются).

## Запуск

Откройте `index.html` в браузере. Скрипт подключён в самом низу `body`, поэтому элементы DOM уже существуют к моменту инициализации.

## Реализованное поведение

- При открытии выбран сегодняшний день, отображается список временных слотов.
- Выбор доступного дня обновляет слоты и сбрасывает ранее выбранное время.
- Выбор свободного слота обновляет блок «Ваша запись».
- Стрелки переключают месяцы; нельзя перейти к месяцу раньше текущего.
- Дни до сегодняшней даты приглушены и недоступны для выбора.
- Блок записи показывает день недели, число, месяц, год и выбранное время.
- Доступность слотов демонстрационная и формируется детерминированно для каждой даты.

## Примечание

Для подключения реального расписания замените демонстрационную функцию `isSlotBusy()` / `getSlotsForDate()` данными сервера. Сейчас занятые слоты генерируются локально для демонстрации работы интерфейса.
