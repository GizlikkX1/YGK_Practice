# frontend-4-practice

React-страница выбора даты и времени для барбершопа «Бритва», подключённая к имитационному API на стороне Vite.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес Vite: `http://localhost:3000`.

Для production-сборки:

```bash
npm run build
npm run preview
```

## API

Сервер реализован как Vite-плагин в `server/server.js`. Для API установлена демонстрационная задержка 650 мс.

- `GET /api/booking/today` — возвращает `{ day, month, year }`.
- `GET /api/slots?day=18&month=10&year=2026` — возвращает `{ date, slots }`.
- `GET /categories` или `GET /api/categories` — список категорий с полем `servicesCount`.
- `GET /categories/{category_id}` или `GET /api/categories/{category_id}` — категория по ID; для неизвестного ID возвращается HTTP 404 и `{ "error": "Category not found" }`.

`month` — 0-индексный: январь = `0`, ноябрь = `10`. Каждый слот имеет поля `{ time, available }`. Данные и формирование наборов слотов находятся в `server/database.js`.

## Проверка сценариев

1. Откройте `http://localhost:3000`: сначала появится «Загрузка…», затем календарь и запрос слотов.
2. Выберите другой день: блок времени покажет «Загрузка слотов…», затем получит расписание.
3. Ошибка загрузки слотов: откройте `http://localhost:3000/?simulateSlotsError=1`. Интерфейс покажет сообщение и кнопку повторного запроса. Сам эндпоинт ошибки также можно проверить по адресу `/api/slots?day=18&month=10&year=2026&error=1`.
4. Ошибка получения даты: откройте `http://localhost:3000/?simulateTodayError=1`. Появится сообщение и кнопка повтора.

При выборе новой даты время сбрасывается. Прошедшие даты заблокированы. Запросы отменяются при смене выбранного дня, а поле `date` в ответе дополнительно проверяется перед применением данных — это защищает от устаревших ответов.

## Структура

- `server/database.js` — сегодняшняя дата, демонстрационные наборы слотов и категории услуг.
- `server/server.js` — Vite middleware для `/api/*`.
- `src/api.js` — клиентские функции `fetchToday()` и `fetchSlots(date)` с обработкой HTTP-ошибок.
- `src/App.jsx` — состояние React и эффекты загрузки.
- `src/components/` — компоненты страницы.
- `src/data/date.js` — чистые функции календаря и форматирования.
- `src/styles/site.css` — стили страницы.
